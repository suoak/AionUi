# Third-party notice — Ember / Dusk default themes

`ember.css` and `dusk.css` contain colour values derived from "Dusk & Ember Themes"
(orca-dusk-ember 1.1.0), <https://github.com/stablyai/orca-plugins/tree/main/plugins/dusk-ember>
at commit `4589eb93e28d8a4e4fdd3a77670297da804e7abe`.

Only colour values were used. They were mapped onto CSBU WorkMate design tokens, and a few
were adjusted for WCAG AA contrast (tertiary text, strong borders and the light status colours).
No code, images, terminal colours or syntax colours were copied.
